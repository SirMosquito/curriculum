# histórico

Arquivo pessoal do André Bernardo. Não é o CV — é a matéria-prima de onde o CV é cortado.

O `cv.md` tem uma página e vive de resumos. Aqui guarda-se o detalhe todo, para que daqui a dois
anos ainda seja possível responder a "o que é que eu fiz em 2022?" sem depender da memória nem do
acesso ao Jira interno.

## Ficheiros

| Ficheiro | O que tem |

| `factos-para-cv.md` | Factos já traduzidos para linguagem de CV (Inglês GB), prontos a colar. |
| `raw/` | Extracção bruta do Jira em TSV. **Fora do git** — ver abaixo. |

## Confidencialidade

Este repositório tem remote público (`github.com/SirMosquito/curriculum`). Os títulos de issues do
Jira interno contêm nomes de clientes, códigos de projeto e endereços internos.

Por isso:

- **`historico/raw/` está no `.gitignore`.** Fica na máquina, não vai para o GitHub.
- Os ficheiros versionados desta pasta estão escritos ao nível do produto e da tecnologia — sem
  nomes de clientes, sem códigos de projeto, sem hostnames internos.

Se alguma coisa for acrescentada aqui a partir de fontes internas, aplicar a mesma regra.

## Idioma

Estes ficheiros são notas de trabalho, tal como o `cv-improvements.md` — ficam em Português. A regra
do Inglês (GB) aplica-se ao CV e a tudo o que sai para o exterior, incluindo o `factos-para-cv.md`,
que já vai escrito em Inglês por ser texto destinado a ser colado no CV.
