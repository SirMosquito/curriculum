# André Bernardo — CV

- **Web:** https://sirmosquito.github.io/curriculum/
- **PDF:** https://sirmosquito.github.io/curriculum/Andre-Bernardo-CV.pdf

The CV is written in Markdown (`cv/cv.md`) and built into `docs/`, which GitHub Pages serves.
The web page keeps a two-column layout; the PDF is a single column so applicant-tracking
systems parse it cleanly. Both come from the same source.

```
npm install
npm run build
```

Requires Node and Google Chrome (set `CHROME_PATH` if it is not in the default location).
